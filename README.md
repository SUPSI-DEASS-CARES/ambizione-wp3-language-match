# ambizione-wp2

Stata analysis code for **Work Package 2** of Igor Francetic's Swiss National Science Foundation (SNSF) Ambizione fellowship.

> **"Disparities in hospital Emergency Department care attributable to language mismatch between patients and hospitals in Switzerland"**

The study estimates disparities in emergency department (ED) resource utilisation caused by language and cultural friction between patients and hospital staff, using administrative claims data covering all Swiss outpatient ED visits from 2015 to 2022 (~7.75 million visits).

---

## Requirements

- **Stata 19**
- User-written packages: `reghdfe`, `rangestat`, `elix22`
  ```stata
  ssc install reghdfe
  ssc install rangestat
  ```
  `elix22` (Elixhauser 2022 comorbidity index) may require manual installation.

---

## Data access

Individual patient-level data (PSA, Medical Statistics) are restricted. Access requires authorisation from the Swiss Federal Statistical Office. Code is made available following STROBE reporting guidelines; data cannot be shared publicly.

---

## Workflow

**Run a single file:**

```stata
do master
```

`master.do` sets all paths and globals and calls the three phases in order:

| Phase | Script | What it does |
|-------|--------|-------------|
| 1 | `prepping.do` | Imports raw PSA/MS/tariff data, collapses to visit level, merges education and comorbidity data, applies exclusions, saves `$dataout/final.dta` |
| 2 | `sampleselection.do` | Counts visits at each exclusion stage; exports attrition tables (CSV) and a LaTeX `\newcommand` file for the flowchart |
| 3 | `analysis.do` | Loads `final.dta`, defines exposure variables, runs regressions, exports tables and figures |

`analysis.do` can also be run standalone (after `prepping.do`) if the globals are already set — see the comment block at the top of that file.

## Repository structure

### Entry point

| File | Purpose |
|------|---------|
| `master.do` | **Run this.** Sets paths/globals and calls all phases in order. |

### Data preparation (Phase 1)

| File | Purpose |
|------|---------|
| `prepping.do` | Master prep — calls year files, merges tariffs, applies exclusions, merges comorbidities and education data |
| `prepping20XX.do` | Year-specific prep (2015–2022): imports PSA files, identifies ED visits, flags tariff types |
| `createlongfile.do` | Reshapes service-level data to long format |
| `covariates.do` | Constructs derived covariates (nationality groups, canton language codes, log transforms, etc.) |
| `genoutcomes.do` | Generates outcome variables |
| `labelling.do` | Applies variable and value labels |
| `tarmeddes.do` | Utility: imports TARMED procedure code descriptions |

### Sample selection (Phase 2)

| File | Purpose |
|------|---------|
| `sampleselection.do` | Counts visits at each exclusion stage; outputs `sampleselection.csv`, `sampleselection_byyear.csv`, and `sampleselection_counts.tex` |

### Analysis (Phase 3)

| File | Purpose |
|------|---------|
| `analysis.do` | Defines `langmatch`/`langmatch_ext`, runs all regressions (main + sensitivity), exports tables and figures |

### LaTeX output

| File | Purpose |
|------|---------|
| `fig1.tex` | CONSORT-style patient selection flowchart; references `\newcommand` values generated by `sampleselection.do` |

## Global macros

Set in `master.do` (edit these to match your environment):

| Global | Description |
|--------|-------------|
| `$datain` | Root of raw PSA input data (year subfolders) |
| `$dataout` | Working/output data directory |
| `$rawms` | Raw Medical Statistics `.DAT` files |
| `$main` | Project root (working directory; do-files must live here) |
